# Лендинг АРИО

Анимированный лендинг Ассоциации развития инклюзивного общества (АРИО), Астана.

Статический сайт: один файл `index.html` и фотографии в `assets/img/`. Сборка не нужна — откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Что внутри

- Сюжет и цифры — из презентации АРИО (октябрь 2026), данные за 2026 год.
- Анимация: глобус из точек фирменных цветов, счётчики, линия модели по скроллу, горизонтальная лента жизненного цикла, шторки фото, круги масштабирования.
- По ТЗ v2.0: появление блоков ≤ 24px / 360ms, отключение анимации кнопкой в шапке и при `prefers-reduced-motion`, лента организаций с паузой, контраст текста ≥ 4.5:1, светлая и тёмная тема.
- Плавный скролл — Lenis 1.1.13 (CDN jsDelivr), шрифты Onest и Golos Text (Google Fonts).
