# Лендинг АРИО

Анимированный лендинг Ассоциации развития инклюзивного общества (АРИО), Астана.

Статический сайт без сборки: `index.html`, логотип `logo-globe.svg` и фото `*.webp` лежат в одной папке. Откройте `index.html` в браузере или опубликуйте через GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Сайт: https://official-nanakai.github.io/ario-landing/

- Сюжет и цифры — из презентации АРИО, данные за 2026 год.
- Анимация: глобус из точек фирменных цветов, счётчики, линия модели, горизонтальный жизненный цикл, шторки фото, круги масштабирования.
- По ТЗ v2.0: появление блоков ≤ 24px / 360ms, кнопка остановки анимации, учёт prefers-reduced-motion, пауза ленты, контраст ≥ 4.5:1, светлая и тёмная тема.
- Внешние ресурсы: шрифты Onest и Golos Text (Google Fonts), плавный скролл Lenis 1.1.13 (jsDelivr).
